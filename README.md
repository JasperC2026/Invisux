## What is Invisux?

Invisux is a bash script to handle privacy / security related things on your system trough the ternimal. Made as an TUI using the [Gum](https://github.com/charmbracelet/gum) library. Commands can also be called directly to make this script also scriptable. Built with simplicity and lightweightness in mind.

## Features

The tool is divided in 3 section: Privacy, Security and Encryption also some basic options of viewing info and license. 

### Encryption
Features: hashing, key generator, AES encryption and GPG. 
### Security 
Features: password generation, system auditing, emptying trash, deleting file (securily) and updating apps
### Privacy
Features: networking options including mac adress randomization, checking tor/public ip, checking ports, dns options. Removing meta data from files.

## Dependencies
The tool needs gum to operate. The rest of dependencies are optional and are handled by the tool. 

List:
gum **REQUIRED**
faker **OPTIONAL**
openssl **OPTIONAL**
shred **OPTIONAL**
exiftool **OPTIONAL**
gpg **OPTIONAL**
steghide **OPTIONAL**
